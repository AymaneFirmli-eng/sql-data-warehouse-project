# SQL Data Warehouse Project

A hands-on SQL Data Warehouse project focused on learning how to design, build, and analyze a data warehouse using SQL.

## Project Overview

This project covers the main steps of a real-world data warehousing workflow:

* Extracting data from raw CSV files
* Cleaning and transforming data
* Loading data into a data warehouse
* Designing **fact and dimension tables**
* Building a **star schema**
* Creating SQL views for analytics
* Writing analytical SQL queries to extract business insights

## Technologies

* MySQL
* MySQL Workbench
* SQL
* CSV files

> This project is based on the SQL Data Warehouse project by **Data With Baraa**, with the SQL Server implementation adapted to MySQL.

## Goal

The goal of this project is to gain practical experience with SQL, data warehousing, ETL processes, database design, and analytical queries using a real-world style dataset.
